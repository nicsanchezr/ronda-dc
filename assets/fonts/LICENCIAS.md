# Tipografías incrustadas

Archivos woff2 (subconjunto latino) incrustados en `dist/index.html` por `build.mjs`.
El nombre del archivo define la familia y el peso: `Familia-Peso.woff2`.

| Familia | Uso | Licencia |
|---|---|---|
| Barlow, Barlow Semi Condensed | Tema Gris de sala | SIL Open Font License 1.1 |
| JetBrains Mono | Tema Gris de sala (datos) | SIL Open Font License 1.1 |
| Atkinson Hyperlegible, Atkinson Hyperlegible Mono | Tema Alto rendimiento | SIL Open Font License 1.1 |

Obtenidas de Google Fonts. Texto de la licencia: https://openfontlicense.org
